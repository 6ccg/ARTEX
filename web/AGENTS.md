# ARTEX 前端项目规范

- 使用恢复后的原有 shadcn / Base UI / Radix 与 Tailwind；优先复用 `src/components/ui/`，遵循公开 API 和原主题变量。
- 保留原有页面布局与交互风格。本次恢复不重新设计页面，也不额外重组业务目录。
- 保留 `web/`、Next.js、React、TypeScript、静态导出与 Go embed 交付。
- 当前后端及其他任务可能并行工作，不回滚、覆盖或格式化他人的改动。并行修改使用独立工作树。
- 保留当前 API、鉴权、中文/英文、SSE、历史/实时合并与去重、审批及执行结果的区别。
- 服务端分页不再对当前页进行全量筛选排序；多选使用稳定业务 ID，保留资产 DSL、发现多视图和任务分类。
- 运行中 Worker 并发调整、全局模型池和单任务覆盖的语义以当前后端为准。
- 默认仅面向宽屏；通过类型检查、相关 lint、核心测试与静态导出，并验证恢复后的主要页面和交互。
- 测试只覆盖明确风险，夹具保留必需数据。文档保持简短，不引入长期兼容层或新的后台服务。
